Webbo Layout è un Paint specializzato per bozze di siti web.

L’utente ha un foglio bianco e, invece di dover disegnare da zero rettangoli, cerchi e linee, apre una voce/menu che gli mostra bozze di layout già pronti e simbolici. 
Li seleziona e li dispone sul foglio come preferisce.

Il risultato non è una pagina web funzionante: è una bozza visiva, fatta di elementi indicativi, che aiuta il creatore a ricordare e comunicare la struttura che poi realizzerà
con il codice.

In altre parole:

    Paint ti fa disegnare qualsiasi cosa;
    Webbo Layout ti dà già i “disegni” tipici di un sito, così devi solo sceglierli e posizionarli.

L’utente seleziona l’elemento dal menu e lo posiziona sulla pagina. Il risultato è una specie di mappa visiva stilizzata: non un sito reale, non HTML, non CSS, non 
un layout automatico con regole tecniche, ma un promemoria grafico della struttura che il creatore userà in seguito come riferimento quando scriverà il codice.

ENGLISH :::

Webbo Layout is a Paint-like tool specialized for website mockups.

The user starts with a blank canvas and, instead of having to draw rectangles, circles, and lines from scratch, opens a menu that displays ready-made, symbolic layout mockups. They select them and arrange them on the canvas however they like.

The result isn’t a working web page. It’s a visual mockup made up of illustrative elements that helps the creator remember and communicate the structure they’ll later build with code.

In other words:

    Paint lets you draw anything;
    Webbo Layout provides the typical “drawings” used in websites, so you just have to choose and position them.

The user selects an element from the menu and places it on the page. The result is a kind of stylized visual map: not a real website, not HTML, not CSS, and not an automatically generated layout based on technical rules, but a visual reminder of the structure the creator will later use as a reference when writing the code.
